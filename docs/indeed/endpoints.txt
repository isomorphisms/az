# Indeed API endpoint inventory
# Verified 2026-08-31 against https://docs.indeed.com/api-guides/
# and the current Indeed Partner Docs.
#
# IMPORTANT: Indeed's main partner APIs are GraphQL. Many named API operations
# share one HTTP endpoint; the GraphQL operations are therefore listed below
# separately so the single transport URL does not hide the API surface.

# OAuth / OpenID Connect
GET  https://secure.indeed.com/oauth/v2/authorize
POST https://apis.indeed.com/oauth/v2/tokens
GET  https://secure.indeed.com/v2/api/appinfo
GET  https://secure.indeed.com/v2/api/userinfo
GET  https://secure.indeed.com/.well-known/keys

# Main GraphQL transport
POST https://apis.indeed.com/graphql

# Real-time API (server-sent events)
GET  https://apis.indeed.com/sse/notifications/message-update

# SCIM 2.0 Users API
GET    https://api.indeed.com/scim/v2/Users
POST   https://api.indeed.com/scim/v2/Users
GET    https://api.indeed.com/scim/v2/Users/{id}
PUT    https://api.indeed.com/scim/v2/Users/{id}
DELETE https://api.indeed.com/scim/v2/Users/{id}
