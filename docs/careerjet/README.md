# Careerjet API

Status: **publisher API requiring a Careerjet API key**.

Official documentation: https://www.careerjet.com/partners/api

Careerjet currently documents one v4 HTTP search endpoint. Access uses HTTP Basic authentication with the API key as the username and an empty password.

## Files

- `endpoints.txt` — literal endpoint inventory.
- `search.md` — authentication, required request context, parameters, and integration notes.
