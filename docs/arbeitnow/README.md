# Arbeitnow Job Board API

Status: **public, free, and usable without an API key**.

Official current overview: https://www.arbeitnow.com/blog/job-board-api

Arbeitnow exposes a free job-search feed aggregating employer postings, largely from applicant-tracking systems. The German/European service and the UK service use parallel endpoints on separate domains.

## Files

- `endpoints.txt` — literal endpoint inventory.
- `search.md` — search/filter behavior and provenance notes.
