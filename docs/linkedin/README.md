# LinkedIn Talent Job Posting API

Status: **restricted partner API, not a public job-search API**.

Official overview: https://learn.microsoft.com/en-us/linkedin/talent/job-postings/api/overview
Current job-posting operation docs: https://learn.microsoft.com/en-us/linkedin/talent/job-postings/api/sync-job-postings?view=li-lts-2026-03
Provisioning API: https://learn.microsoft.com/en-us/linkedin/talent/middleware-platform/provisioning-api

LinkedIn's current overview says it is **not accepting new partnerships for the Job Posting API** and directs prospective integrations toward Apply Connect. Use of the Job Posting APIs is restricted to developers approved by LinkedIn under an API agreement.

There is no general public LinkedIn job-search endpoint in this inventory.

## Files

- `endpoints.txt` — job-posting, auth, and partner-provisioning routes.
- `job-posting.md` — lifecycle operations and versioning.
- `access-and-provisioning.md` — restricted access, OAuth, and child applications.
