# USAJOBS APIs

Status: **official U.S. federal public-data APIs**. The current job-search endpoint requires a USAJOBS API key; Historic JOAs, Announcement Text, and code-list endpoints are publicly consumable without authentication.

Official API reference: https://developer.usajobs.gov/api-reference/

The current reference describes three principal REST APIs—Search, Historic JOAs, and Announcement Text—plus a large set of unauthenticated code-list endpoints used to interpret/filter job data.

## Files

- `endpoints.txt` — complete route list exposed by the current API-reference overview.
- `job-search.md` — current-job search, authentication, and pagination.
- `bulk-and-codelists.md` — historic/bulk job data and lookup tables.
